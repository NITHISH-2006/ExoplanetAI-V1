# ExoplanetAI-V1

**AI for Exoplanets**  
A Machine Learning / AI project focused on exoplanet detection / prediction using python and Streamlit.

---

## 📌 Project Overview

`ExoplanetAI-V1` is a Python-based AI application designed to work with exoplanet data and deliver intelligent predictions or insights related to exoplanetary science. It includes a web interface powered by **Streamlit**, a trained model, and an easy-to-deploy app structure.

---

## 🧠 Features

✔️ Interactive **Streamlit web app** interface  
✔️ Integrated **AI/ML model** (`model.joblib`) for predictions  
✔️ Simple deployment environment configured  
✔️ Folder structure ready for expansion and improvement
